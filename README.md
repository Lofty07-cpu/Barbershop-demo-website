# Barbershop Website Template

A modern, responsive one-page website template built for barbershops and grooming businesses.

This project was created as a reusable website template that can be customised for different businesses by changing the branding, colours, content, services, images and contact information.

## Features

- Responsive design for desktop, tablet and mobile
- Modern hero section
- Services section
- About section
- Pricing section
- Customer reviews
- Contact information
- WhatsApp/contact buttons
- Mobile-friendly navigation
- Reusable layout and styling
- Easy to customise for different businesses

## Purpose

The main goal of this project is to provide small businesses with an affordable and professional website option without building every website completely from scratch.

The same structure can be reused and customised for different clients while still allowing each business to have its own branding and content.

## Built With

- HTML5
- CSS3
- JavaScript

## Customisation

The template can be customised by changing:

- Business name
- Logo
- Brand colours
- Fonts
- Services
- Prices
- Images
- Contact details
- WhatsApp number
- Social media links
- Testimonials
- Section layouts
